# X.509 certificates (RFC 5280, DER)

A schema-directed X.509 certificate parser written in Daedalus, with a
Rust test suite that runs against the parser generated by
`daedalus compile-rust`.  Where the sibling [ASN.1 example](../asn1)
parses arbitrary DER into a generic value tree, this spec knows the
RFC 5280 certificate structure: it produces named fields, decodes the
common extensions, and enforces certificate-level rules on top of
strict DER.

## What is parsed

```
Certificate
  tbsCertificate
    version               0..2 (uint; the [0] EXPLICIT field, absent = 0 = v1)
    serialNumber          raw minimal two's-complement bytes
    signature             AlgorithmIdentifier { algorithm: OID arcs,
                                                parameters: Any or null }
    issuer / subject      array of RDNs; each RDN an array of
                          { attrType: OID arcs, attrValue: Any }
    validity              { notBefore, notAfter }, each
                          {"$utcTime": bytes} or {"$generalizedTime": bytes}
    subjectPublicKeyInfo  { algorithm, subjectPublicKey: {unused, bytes} }
    issuerUniqueID        null or {"$$just": {unused, bytes}}   (v2+)
    subjectUniqueID       likewise                              (v2+)
    extensions            null or {"$$just": [Extension]}       (v3)
  signatureAlgorithm      AlgorithmIdentifier
  signatureValue          BIT STRING {unused, bytes}
```

(`attrType`/`attrValue` are RFC 5280's `type`/`value`; renamed because
`type` is a Rust keyword.)

Each Extension is `{extnID, critical, extnValue}` where extnValue is
decoded for the standard extensions and kept raw otherwise:

| OID       | Extension            | Decoded value |
|-----------|----------------------|---------------|
| 2.5.29.19 | BasicConstraints     | `{"ca": bool, "pathLen": null or {"$$just": n}}` |
| 2.5.29.15 | KeyUsage             | BIT STRING `{unused, bytes}` |
| 2.5.29.17 | SubjectAltName       | list of `$dnsName` / `$rfc822Name` / `$uri` (IA5 bytes), `$ipAddress` (raw bytes), `$directoryName` (a full Name), `$otherForm` fallback |
| 2.5.29.14 | SubjectKeyIdentifier | raw bytes |
| 2.5.29.35 | AuthorityKeyIdentifier | `{"keyId": maybe bytes, "rest": bytes}` |
| 2.5.29.37 | ExtKeyUsage          | list of OID arc arrays |
| other     | --                   | `{"$raw": bytes}` |

ANY slots (algorithm parameters, attribute values, unknown extension
forms) fall back to the generic ASN.1 value union shared with the
[asn1 example](../asn1) -- so a PrintableString CN comes out as
`{"$printableString": bytes}` and RSA's NULL parameters as
`{"$null": {}}`.

## Enforced rules

All the strict-DER rules of the asn1 example (definite and minimal
lengths, minimal tag numbers and INTEGERs and OID subidentifiers,
canonical booleans, zero bit-string padding, shape-checked times), plus
certificate-level checks:

* version, when present, must be 1 or 2 -- encoding 0 would encode the
  DEFAULT, which DER forbids; higher values are out of range,
* unique IDs require v2+, extensions require v3,
* `critical` and BasicConstraints' `cA` must not be encoded as their
  DEFAULT FALSE,
* Extensions, RDNs, and GeneralNames honor their `SIZE (1..MAX)` bounds,
* extension values must consume their OCTET STRING exactly; the
  tbsCertificate/BIT STRING/etc. nesting must consume exactly as well,
* GeneralName alternatives must be context-class tags.

Not checked: signatures (parsing only), serial-number positivity
(real-world CAs have shipped violations), DER SET ordering, UTF-8
validity, calendar validity of dates.

## Layout

```
x509.ddl            the Daedalus spec (self-contained, no imports)
Makefile
tests/certs/        committed .der corpus + generate.sh (its recipe)
rust/               Rust consumer crate with the test suite
  src/lib.rs        parse() plus JSON navigation helpers
  tests/cert_tests.rs        deep assertions on the real corpus
  tests/structure_tests.rs   synthetic-DER positive/negative tests
gen/                generated by `make gen` (gitignored)
```

## The certificate corpus

`tests/certs/` holds ten committed DER certificates: openssl-generated
RSA-2048 / ECDSA P-256 / Ed25519 self-signed certificates, a rich
subjectAltName example, a CA certificate with path length, an
extendedKeyUsage example, a mixed UTCTime/GeneralizedTime validity, a
true v1 certificate, and two real-world roots (ISRG Root X1, DigiCert
Global Root G2) taken from the system trust store.  `generate.sh`
records the exact recipe; `make regen-certs` reruns it (fresh keys and
dates -- the pinned assertions in `cert_tests.rs` then need re-pinning;
serial numbers and subjects are pinned in the recipe and survive).

## Usage

```sh
make interp    # parse a sample with the Daedalus interpreter
make test      # compile-rust + cargo test (the main entry point)
make smoke     # run the generated CLI driver on a sample
```

`make test` runs

```sh
daedalus compile-rust --determinize --out-dir=gen --rts-path=../../../rts-rust x509.ddl
cd rust && cargo test
```

Both `gen/` and `rust/` depend on the Rust runtime in
[`rts-rust/`](../../rts-rust) at the repository root by path, so they
share a single runtime instance.  Building requires Rust >= 1.85 (the
generated crate uses `edition = "2024"`).  If `daedalus` is not on your
PATH, use `make DAEDALUS="cabal exec daedalus --"`.

## Tests

* `cert_tests.rs` asserts deeply on every corpus certificate: versions,
  exact serial bytes, algorithm OIDs inner and outer, every subject
  attribute, validity variants and pinned dates, SPKI algorithm/params/
  key sizes, and each decoded extension (SAN entries in order, KeyUsage
  bits, BasicConstraints, SKI/AKI relationships).
* `structure_tests.rs` builds certificates byte-by-byte with a small
  DER builder, then checks positives (minimal v1, v2 + uniqueID,
  unknown extensions kept raw, directoryName recursion) and ~35
  negatives (DEFAULT-encoding violations, version gating, truncations,
  non-minimal encodings, empty SIZE(1..) sequences, bad times, bit
  string violations, ...).

The parsed value is navigated as `serde_json::Value`; note that the
Rust runtime serializes `maybe` as `null` / `{"$$just": v}` (the
interpreter's `--json` uses `$just` -- one `$`).

## Notes

* Named character classes (`def $foo = ...`) are not supported by the
  Rust backend; character sets are inlined in the spec.
* See the [Daedalus tool documentation](../../docs-src/source/tool-docs/daedalus.rst)
  for `compile-rust` options and current limitations, and
  [`formats/asn1/`](../asn1) for the generic-ASN.1 sibling example.
