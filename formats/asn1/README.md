# ASN.1 (DER)

A generic [ASN.1](https://en.wikipedia.org/wiki/ASN.1) DER parser written in
Daedalus, together with a Rust test suite that runs against the parser
generated by `daedalus compile-rust`.  This is also the in-repo example of
the compile-rust workflow: generating a Rust crate from a spec and consuming
it from another crate.

The spec ([asn1.ddl](asn1.ddl)) parses a single DER-encoded value into a
recursive tag/length/value tree.  It is schema-agnostic: it decodes the
common universal types and keeps everything else (application,
context-specific, and private class tags, and unhandled universal tags such
as ENUMERATED or REAL) as a generic `other` value, recursing into it when it
is constructed.

## Supported types and their JSON shapes

The generated Rust types are `serde::Serialize`; union variants serialize as
one-key objects.  The interpreter's `--json` output has the same shape.

| ASN.1 type            | Variant             | Value |
|-----------------------|---------------------|-------|
| BOOLEAN               | `$boolean`          | `true` / `false` |
| INTEGER               | `$integer`          | raw big-endian two's-complement content bytes, e.g. `[1, 0]` for 256 |
| BIT STRING            | `$bitString`        | `{"unused": n, "bytes": [...]}` |
| OCTET STRING          | `$octetString`      | content bytes |
| NULL                  | `$null`             | `{}` |
| OBJECT IDENTIFIER     | `$oid`              | decoded arcs, e.g. `[1, 2, 840, 113549, 1, 1, 11]` |
| UTF8String            | `$utf8String`       | content bytes (not validated as UTF-8) |
| PrintableString       | `$printableString`  | content bytes (character set enforced) |
| IA5String             | `$ia5String`        | content bytes (7-bit enforced) |
| UTCTime               | `$utcTime`          | content bytes (shape enforced: `YYMMDDHHMMSSZ`) |
| GeneralizedTime       | `$generalizedTime`  | content bytes (shape enforced: `YYYYMMDDHHMMSS[.f+]Z`) |
| SEQUENCE / SET        | `$sequence` / `$set`| array of child values |
| everything else       | `$other`            | `{"tagClass": c, "constructed": b, "tagNum": n, "content": {"$children": [...]} or {"$raw": [...]}}` |

INTEGER content is deliberately kept as raw bytes rather than decoded, so
arbitrarily large values (e.g. RSA moduli) round-trip without needing
arbitrary-precision integers in the generated code.

## DER strictness

The parser accepts DER, not general BER.  It rejects:

* indefinite lengths, and non-minimal length encodings (long form where the
  short form fits, leading zero length octets),
* non-minimal tag numbers (high form where the low form fits, leading `0x80`
  septets) and non-minimal INTEGER and OID subidentifier encodings,
* booleans other than `0x00` / `0xFF`,
* constructed encodings of the string and time types,
* nonzero padding bits in BIT STRING,
* malformed time bodies (wrong digit counts, missing `Z`, trailing zeros in
  a GeneralizedTime fraction),
* trailing bytes after the top-level value.

Not checked (a schema-aware consumer's job): UTF-8 validity of UTF8String,
DER ordering of SET elements, and calendar validity of times.  Tag numbers
and lengths larger than `2^64 - 1` are rejected rather than decoded.

## Layout

```
asn1.ddl            the Daedalus spec (self-contained, no imports)
Makefile
rust/               Rust consumer crate with the test suite
  src/lib.rs        parse() helper wrapping the generated entry point
  tests/der_tests.rs
gen/                generated by `make gen` (gitignored)
```

## Usage

```sh
make interp    # parse a sample with the Daedalus interpreter
make test      # compile-rust + cargo test (the main entry point)
make smoke     # run the generated CLI driver on the sample
```

`make test` runs

```sh
daedalus compile-rust --determinize --out-dir=gen --rts-path=../../../rts-rust asn1.ddl
cd rust && cargo test
```

The generated `gen/` directory is a complete crate (library plus a small CLI
driver in `gen/src/main.rs`).  Both `gen/` and `rust/` depend on the Rust
runtime in [`rts-rust/`](../../rts-rust) at the repository root by path, so
they share a single runtime instance.  Building requires Rust >= 1.85 (the
generated crate uses `edition = "2024"`).  If `daedalus` is not on your
PATH, use `make DAEDALUS="cabal exec daedalus --"`.

## Tests

`rust/tests/der_tests.rs` covers each supported type plus framing, length,
and tag edge cases: positive tests compare hand-encoded DER against expected
JSON (`parse(bytes)` returns `serde_json::Value`), and negative tests check
that BER-legal-but-DER-illegal or corrupt encodings fail to parse.  To add a
test, encode the bytes by hand and assert with `serde_json::json!`:

```rust
#[test]
fn my_test() {
    assert_eq!(ok(&[0x02, 0x01, 0x2A]), json!({"$integer": [42]}));
}
```

## Notes

* Named character classes (`def $foo = ...`) are not supported by the Rust
  backend, which is why the PrintableString character set is inlined in the
  spec.
* See the [Daedalus tool documentation](../../docs-src/source/tool-docs/daedalus.rst)
  for the full list of `compile-rust` options and current limitations.
